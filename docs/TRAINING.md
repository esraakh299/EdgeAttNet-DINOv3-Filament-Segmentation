# Training and full-method provenance

## Scope of the optional training branch

The committee demo's `TRAIN_FROM_SCRATCH = False` path **does not require training**.
Setting it to `True` requests a recreation of the task-specific segmentation model from the
original **pretrained** DINOv3 ConvNeXt-Base encoder. In this context, "from scratch"
means a new task fine-tuning run, *not* self-supervised pretraining of DINOv3 itself.

The model trainer is present as source (`src/training_worker.py`) and exposes the original
method: GroupNorm, balanced augmentation, 1024px patches, AdamW, EMA=0.99 and 55
Dice-stage epochs with a fixed-PQ selection monitor. Training can take several GPU sessions,
and the historical weights may not be bit-identical owing to GPU/kernel nondeterminism.

### Requirements for training mode

1. Official competition train data and complete COCO annotation JSON.
2. Original curated split tables (`physical_images_split.parquet`,
   `annotation_sets_split.parquet`) and the original training-only mask artifacts.
3. The verified official DINOv3 ConvNeXt-Base pretrained *encoder* state-dict,
   provided as a mounted local file. This may be gated upstream; committee inference is not.
4. A GPU and potentially multiple sessions to finish 55 epochs.
5. For **full filter retraining**, genuine independent OOF probability maps covering
   each of the 566 training physical images, generated by held-out fold models.

`scripts/retrain_base.py` runs the original training worker and writes the best EMA
snapshot to `EdgeAttNet_DUAL_v1/dino_convnext_base/dice_best_ema.pth`.
`scripts/export_model.py` then extracts the inference-only `state_dict`.

### Four OOF models · original training-only cross-fitting

The additional OOF notebooks are the original DINOv3-Base 55-epoch fold recipe,
not DINO-Small and not four leaderboard ensemble members.

| Notebook | Fold models | Default |
|:--|:--|:--|
| `notebooks/04_OOF_Folds_01.ipynb` | 0 and 1 | Load pretrained |
| `notebooks/05_OOF_Folds_23.ipynb` | 2 and 3 | Load pretrained |

Each notebook exposes `TRAIN_OOF_FROM_SCRATCH = False`. In that default mode,
attach the original pair notebook output containing the two `fold_X/fixed_final_ema.pth`
files and, optionally, existing `prob_oof/fold_X/` arrays. Alternatively attach
`fold_X_model.pth` + the `fold_X_model.json` provenance created by
`scripts/export_oof_models.py`; these are the recommended smaller inference-only
artifacts. Regenerating held-out maps from model-only weights requires a CUDA GPU.
The notebooks verify the training/heldout roster, 2-day temporal embargo, split
and COCO SHA fingerprint, fold manifest, and metadata. They use native 8-way TTA
and save FP16 `.npy` maps and `.json` checksums.

Set `TRAIN_OOF_FROM_SCRATCH = True` only for a new fold-training run, with two
GPUs and the official pretrained DINOv3 ConvNeXt-Base encoder state_dict. The
fixed 55-epoch EMA model is trained on the original fold's training images and
used to infer only on the held-out subset. The original validation images are
excluded from all four fits. A single Kaggle session may not finish all folds;
attach the **whole previous output** and set `RESUME_ROOT` to continue. For the pinned published models, fold provenance sidecars are generated automatically from the original manifests bundled in `data/oof/`.

After both pair notebooks are complete, audit all 566 OOF maps:

```bash
python scripts/audit_oof_coverage.py \
  --pair-01 /path/to/DINO_OOF_Folds01 \
  --pair-23 /path/to/DINO_OOF_Folds23 \
  --out /kaggle/working/oof_verified
```

Then fit the selector using the verified index, **not** in-sample full-model maps:

```bash
python scripts/fit_filter_oof.py \
  --dataset /kaggle/input \
  --splits data/splits \
  --oof /kaggle/working/oof_verified \
  --out /kaggle/working/learned_filter
```

`scripts/fit_filter_oof.py` uses the locked CatBoost depth-5/550-tree recipe;
this is a fixed-config refit and does *not* repeat the historical nested model
search, so numerical identity with the submitted `.joblib` is not guaranteed.
For the default committee run, load the published frozen filter directly.

## Artifact packaging for the committee

Produce a lean inference state-dict without optimizer/scheduler/history using:

```bash
python scripts/export_model.py \
  --source /path/to/dice_best_ema.pth \
  --output models/edgeattnet_dinov3_base_best.pth
```

Keep the three artifacts (`.pth`, `.joblib`, `.json`) at a URL or Kaggle dataset
accessible *without login*. The source ZIP does not embed the large binaries; the default notebook downloads the published inference files automatically.
